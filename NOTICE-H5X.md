# H5X wireframe adaptation

Based on [H7-Tex/TX](https://github.com/H7-Tex/TX), upstream commit `8204b29`.

Retained and adapted: the Bricolage / Fragment font pairing, the canvas ASCII block renderer and its drag/scatter physics, synthesized interaction sound, and the concise editorial approach.

H5X changes: an 18-column H5X glyph, warm red accents, five separate pages, six floating hover/focus previews, a shared automatically refreshed CTFtime feed for team 438630, researched H5X content, paginated event/build records, accessible motion controls, and three team event photographs. SHIELD photographs are excluded.

The upstream checkout had no repository-level LICENSE file at the inspected revision; this notice records provenance and does not assign a new license to upstream code or fonts. This H5X adaptation is maintained separately; the upstream repository and website are unchanged.
